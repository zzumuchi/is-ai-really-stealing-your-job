# Is AI Really Stealing Your Job?

<p align="right"><a href="./README.md">English</a> | <strong>한국어</strong></p>

AI가 노동시장을 어떻게 변화시키고 있는지 탐구하는 인터랙티브 데이터 스토리텔링 프로젝트입니다.

이 프로젝트는 **연세대학교 2026-1 데이터시각화입문 과목**에서 진행했습니다.

## 프로젝트 개요

이 프로젝트는 “AI가 내 일자리를 빼앗을까?”라는 질문에 데이터를 통해 답합니다. 산업혁명부터 오늘날까지의 고용 구조 변화, 실제 AI 도입 추세, 974개 직업의 자동화 위험도를 시각화합니다.

## 구성

스크롤에 따라 전개되는 총 15개 섹션의 내러티브로 구성되어 있습니다.

| 섹션 | 내용 |
| --- | --- |
| S1 | 히어로 화면 — 핵심 질문 제시 |
| S2 | 레이싱 바 차트 — 1800~2024년 산업별 고용 변화 |
| S3 | 전환 — “일자리가 사라지는가?”와 “업무가 변하는가?” |
| S4 | 워드 클라우드 — 하나의 직업은 여러 업무의 묶음 |
| S5 | 히트맵 — 25개 직업 × 30개 업무 유형 |
| S6 | 인터랙티브 히트맵과 레이더 차트 — 직업별 업무 구성 탐색 |
| S7 | 트리맵 — AI 활용 비중이 가장 높은 업무 유형 |
| S8–S9 | 발산형 막대 차트 — 자동화(대체)와 증강(협업) 비교 |
| S10 | Part 3 전환 — 실제 고용 데이터 |
| S11 | 선 차트 — AI 도입 지수와 전체 고용 지수 비교(2022~2025) |
| S12 | 버블 차트 — 업무 구성과 고용 성장률의 관계 |
| S13–S14 | 결론 — 질문의 관점 전환 |
| S15 | 인터랙티브 진단 — 974개 직업을 검색하고 자동화·증강·안정 업무 비중 확인 |

## 기술 스택

- **D3.js v7** — 레이싱 바, 트리맵, 발산형 막대, 선 차트
- **Chart.js 4** — 레이더 차트, 버블 차트
- **Plotly 2** — 히트맵
- Vanilla HTML / CSS / JavaScript — 별도 빌드 도구 없음

## 로컬 실행

별도의 설치 과정이 필요하지 않습니다. 브라우저에서 `index.html`을 직접 엽니다.

```bash
open index.html
```

## 데이터 출처

- BLS(Bureau of Labor Statistics) — 산업별 고용 시계열, 직업별 임금 및 고용 규모
- O\*NET — 직업별 업무 특성과 중요도 점수
- Stanford HAI / Goldman Sachs — AI 도입 지수

## 핵심 인사이트

- AI 도입은 빠르게 증가했지만 전체 고용 지수는 거의 변하지 않았습니다.
- AI가 인간을 대체하는 자동화보다 인간과 함께 일하는 증강이 훨씬 더 널리 나타납니다.
- 반복적·사무적인 업무 중심 직업은 위험도가 높은 반면, 대인 관계와 인지 능력이 중요한 직업은 상대적으로 회복력이 높습니다.
